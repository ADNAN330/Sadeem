# Sadeem
### Sadeem is where knowledge intertwines, where the stars connect together creating a new form.

Sadeem is a project of mine, that focuses on sharing data inbetween the different devices of the user, be it from a PC to mobile or other devices. 
The idea itself imerges from the sky, how imaginary lines are created to connect between stars, as if they share wisdom, and that is the meaning behind Sadeem.
It now works on sharing text only, which will hopefully change in the future to cover more datatypes as the regular user might need in a normal day of life.
